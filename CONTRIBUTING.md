# Contributing

## About This Project

This is a **proof-of-concept (POC)** project I built to solve problems I needed to overcome. It's shared publicly in case it's useful to others.

## Status

- **No active maintenance** - I work on this when I need to
- **No support** - Use at your own risk
- **No guarantees** - It works for my use cases

## Want to Contribute?

Feel free to:

- Fork it and do whatever you want
- Open PRs if you fix something - I'll review when I can
- Open issues for bugs - no promises on fixes
